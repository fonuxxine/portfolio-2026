# samirad. portfolio

A static site: open `index.html` in a browser, or serve the folder with any static host.

- `index.html` — home page with the three case studies
- `context-cards.html` — the "Understand language in context" case study
- `img/`, `fonts/` — recordings, posters and the Obviously Demo cuts the pages use
- `*.js` — small page scripts (card carousel, spacing redlines, the thoughts line, video playback)

Keyboard helpers while viewing: **G** toggles the layout grid, **S** toggles spacing redlines.
